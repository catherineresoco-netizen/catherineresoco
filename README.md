# Catherine Resoco — Personal Portfolio

A responsive, single-page portfolio showcasing Catherine's work as a U.S. Marine Corps veteran, Future Operating Base founder, and aspiring international relations scholar.

## Website

Once GitHub Pages is enabled, visit:

https://catherineresoco-netizen.github.io/catherineresoco/

## Technology

HTML, CSS, and vanilla JavaScript. No build step required.

## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the deployment workflow to complete.

Subsequent edits to `index.html` on `main` will publish automatically.

## Editing

The portfolio is contained in `index.html`. Its content is based on the master résumé, plus the "What's Next for Me" goals and separately identified exploratory projects. Review all details before sharing publicly.
